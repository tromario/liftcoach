# LiftCoach

Веб-приложение (PWA) — тренер по технике троеборья (присед, жим, тяга) в реальном времени.
Работает в Safari на iPhone без установки из App Store. Поза распознаётся на телефоне (MediaPipe Pose),
видео никуда не отправляется.

Профиль: AWPC raw, присед с низким грифом, тяга классика и сумо.

## Структура
- `index.html` — разметка
- `src/main.js` — логика: камера, скелет, углы, голос
- `public/` — manifest, иконки, service worker; сюда же setup кладёт wasm и модели
- `scripts/setup.mjs` — копирует MediaPipe wasm и скачивает модели (после `npm install`)
- `.github/workflows/deploy.yml` — автодеплой на GitHub Pages при push в main

## Запуск
    npm install
    npm run dev        # https://<IP-мака>:5173 — открыть на айфоне в той же Wi-Fi

`vite-plugin-mkcert` сам создаёт сертификат. На айфон один раз ставится корневой сертификат
(`~/.vite-plugin-mkcert/rootCA.pem`, см. ниже).

Сборка для хостинга: `npm run build` → папка `dist/`.

## Сертификат на айфоне (один раз)
1. AirDrop файла `~/.vite-plugin-mkcert/rootCA.pem` на айфон
2. Настройки → «Профиль загружен» → Установить
3. Основные → Об этом устройстве → Доверие сертификатам → включить

## Модули
- `src/pose.js` — камера, MediaPipe, отрисовка скелета
- `src/bench.js` — жим: предплечье в низу, путь грифа, вершина, отрыв таза, темп, мёртвая точка; опционально команды Старт/Жим/Стойка
- `src/squat.js` — присед: повторы, глубина, наклон, гриф, пятки, итог подхода, команды судьи
- `src/profile.js` — автокалибровка пропорций (бедро, голень, корпус, рука) и «обычный» наклон
- `src/framing.js` — проверка кадра (боком, целиком, расстояние, уровень)
- `src/level.js` — уровень телефона по акселерометру
- `src/config.js` — все пороги
- `src/recorder.js` — запись: сырое видео для тренера, видео со скелетом и покадровые данные для разбора
- `src/live.js` — режим «живые углы»
